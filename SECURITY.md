# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Orion, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report the issue privately by opening a **private vulnerability report** through GitHub's Security Advisories.

When reporting a vulnerability, please include as much of the following information as possible:

* A description of the vulnerability
* The affected version(s)
* The type of vulnerability, if known
* The affected source files or components
* Steps to reproduce the issue
* A proof of concept, if available
* The potential impact of the vulnerability
* Any suggested mitigation or fix, if available

Providing detailed reproduction steps and technical information will help investigate and address the issue more efficiently.

## Supported Versions

Security fixes are provided for the latest development version of Orion. Older versions may not receive security updates.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅         |
| Older releases | ❌         |

## Disclosure

Please allow reasonable time for a vulnerability to be investigated and, when appropriate, fixed before publicly disclosing it.

Thank you for helping improve the security and reliability of Orion.
